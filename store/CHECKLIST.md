# 출시 체크리스트

## 계정·계약
- [ ] Apple Developer Program 가입 (연회비 유료 — 현재 금액은 developer.apple.com에서 확인)
- [ ] App Store Connect에서 새 앱 만들기 (이름이 이미 쓰이고 있으면 부제를 붙여 조정)
- [ ] 유료 앱이면: Paid Apps Agreement(계약·세금·은행 정보) 입력 + 가격 선택

## 출시 전 꼭 고칠 것
- [ ] **글꼴 파일 넣기:** 외부 글꼴 호출은 없앴어요. `www/fonts/`에 글꼴 4개를 넣으면 원래 디자인 그대로예요.
- [x] 외부 번역 API 제거 완료 — 앱이 외부 서버와 통신하지 않음
- [x] 요청·지원 메일: appellemoi.app@gmail.com (Gmail에서 계정을 직접 만들고, 이 주소를 App Store Connect 지원 연락처에도 입력)
- [x] 개인정보 처리방침·지원 페이지 작성 완료(`site/`) — GitHub Pages 등에 올려서 URL만 입력
- [ ] App Privacy 답변: 실제 동작 기준으로 작성 (현재 외부 통신 없음 — 수집 항목 없음으로 답변 가능)

## 심사 통과 가능성 (가이드라인 4.2 최소 기능)
웹사이트를 그대로 감싼 앱은 반려될 수 있어요. 아래를 갖추면 안전해져요.
- [x] 콘텐츠 앱 내 포함, 오프라인 동작(번역 제외)
- [x] 매일 학습 알림(Local Notifications) 추가됨 — 실기기에서 권한·예약 동작 확인 필요
- [ ] 햅틱, 홈 화면 위젯 등 네이티브 기능

## 제출 자료
- [ ] 스크린샷: 시뮬레이터에서 3~5장 (실제 화면만)
- [ ] 1024×1024 아이콘: `store/icon-1024.png` (투명·둥근 모서리 없음)
- [ ] `store/listing-ko.md` 입력, 심사 메모 입력
- [ ] 수출 규정: 표준 HTTPS만 사용
- [ ] TestFlight로 실기기 테스트 후 심사 제출

## 판매 방식
- 유료 다운로드: 코드 변경 없이 가능, 가장 간단해요.
- 구독/인앱결제: StoreKit 연동 개발이 추가로 필요해요.
